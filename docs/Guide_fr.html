NetISO Manager

Jouez à vos ISO Xbox 360 rangés sur votre PC, directement depuis la liste de jeux d'Aurora.

Ce qu'il vous faut Installation en 5 étapes Jouer Jeux sur plusieurs disques En cas de problème

Comment ça marche

Vos fichiers ISO restent sur le PC. NetISO Manager crée pour chaque jeu une petite « tuile » qu'il envoie sur la console. Aurora affiche cette tuile comme un jeu normal, avec sa pochette. Quand vous lancez le jeu, la console le lit sur le PC par le réseau.

Le PC doit donc rester allumé, avec NetISO Manager ouvert, pendant que vous jouez à ces jeux. Les jeux déjà installés sur la console fonctionnent toujours, PC allumé ou non.

Ce qu'il vous faut

  • Une Xbox 360 RGH ou JTAG avec Aurora et DashLaunch installés.
  • Le plugin NetISO.xex de cOz. Il est fourni avec ce logiciel et s'installe d'un clic à l'étape 3 : vous n'avez rien à télécharger.
  • Un PC sous Windows 64 bits.
  • La console et le PC sur le même réseau, de préférence par câble Ethernet.
  • Vos jeux au format .iso, ou sous forme de dossiers de jeu (un dossier qui contient default.xex).

Installation en 5 étapes

Étape 1. Ouvrez NetISO Manager sur le PC.

Au premier démarrage du serveur, Windows peut afficher une alerte du pare-feu. Cochez « Réseaux privés » puis cliquez sur « Autoriser l'accès ». Sans cela, la console ne peut pas joindre le PC.

Étape 2. Indiquez vos dossiers de jeux.

Dans la zone 1, cliquez sur « Ajouter un dossier... » et choisissez le dossier qui contient vos jeux, qu'ils soient en ISO ou en dossiers de jeu. Répétez pour chaque dossier, même s'ils sont sur des disques différents. Vos jeux apparaissent dans la zone 2.

Étape 3. Reliez la console.
  1. Allumez la console et laissez-la sur Aurora.
  2. Dans la zone 3 de NetISO Manager, cliquez sur « Chercher » à côté de « Adresse IP de la console » : le logiciel cherche la console sur votre réseau et remplit son adresse. S'il ne trouve rien, relevez l'adresse dans les réglages réseau de la console ou d'Aurora (exemple : 192.168.1.50) et tapez-la.
  3. Cliquez sur « Installer le plugin sur la console » et confirmez. Le logiciel envoie le plugin, lui indique l'adresse de votre PC et l'ajoute au démarrage de la console.
  4. Redémarrez la console.

Cette étape ne se fait qu'une seule fois.

Étape 4. Envoyez vos jeux.

Vérifiez que la zone 4 indique « En marche ». Sinon, cliquez sur « Démarrer le serveur ». Puis cliquez sur « Synchroniser avec Aurora » et attendez le message « Terminé » dans le journal.

Étape 5. Montrez le dossier à Aurora.
  1. Dans Aurora, ouvrez les réglages, partie Contenu, puis la gestion des chemins de scan.
  2. Ajoutez le chemin Hdd1:\NetISO avec une profondeur de scan de 2.
  3. Lancez un scan.

Cette étape ne se fait qu'une seule fois. Vos jeux apparaissent dans la liste avec leurs pochettes.

Jouer

  1. Sur le PC, NetISO Manager est ouvert et son serveur est « En marche ».
  2. Sur la console, choisissez un jeu dans Aurora et appuyez sur A.
  3. L'écran reste noir une ou deux secondes, puis le jeu démarre.

Pour quitter : bouton Guide, puis retour à Aurora, comme pour n'importe quel jeu.

Ajouter un jeu plus tard

Copiez le nouvel ISO ou le nouveau dossier de jeu dans l'un de vos dossiers. NetISO Manager le remarque et vous propose de le transférer. Répondez « Oui », puis lancez un scan dans Aurora.

Jeux déjà installés sur la console

Si un jeu est à la fois sur la console et en ISO sur le PC, seule la version de la console apparaît : pas de doublon. Si vous supprimez le jeu de la console pour gagner de la place, cliquez sur « Synchroniser avec Aurora » : il réapparaît, joué cette fois depuis le PC.

Voir l'écran de la console depuis le PC

Pendant l'installation, vous n'avez pas besoin de changer d'entrée HDMI ni de regarder la télévision. Cliquez sur « Voir l'écran de la console » dans la zone 3 : une fenêtre affiche ce que montre la console, avec une nouvelle image toutes les trois secondes environ. C'est une aide pour suivre les étapes, pas une vidéo : la manette reste nécessaire pour naviguer dans Aurora.

Cette fonction utilise le serveur web d'Aurora. S'il vous demande un utilisateur et un mot de passe, ce sont ceux des réglages d'Aurora, à la rubrique du serveur HTTP (xboxhttp / xboxhttp par défaut).

Seulement les jeux jouables : la vue « Available games »

Chaque « Synchroniser avec Aurora » dépose aussi trois petits scripts dans Aurora. Lancez-en un une seule fois, et Aurora s'ouvrira sur une vue des jeux réellement jouables :

  1. Dans Aurora, ouvrez les scripts utilitaires et lancez « NetISO Setup ».
  2. Répondez « Yes » : Aurora redémarre.

Ensuite, Aurora s'ouvre sur la vue « Available games » :

  • les jeux joués depuis le PC sont masqués quand le serveur de NetISO Manager ne tourne pas, et reviennent quand il tourne ;
  • les disques d'installation et les packs de voix, qui ne sont pas des jeux, sont masqués. Tous les disques de jeu restent visibles : certains jeux, comme Battlefield 4, lancent leur campagne depuis le disque 2.

Aurora n'applique ses filtres qu'en construisant sa liste. Quand le serveur démarre ou s'arrête, NetISO Manager relance donc Aurora pour vous, mais seulement si Aurora est à l'écran : jamais pendant une partie.

Pour tout revoir, choisissez la vue « Show All » dans le menu Quick View d'Aurora. Vous pouvez aussi choisir le sous-titre « NetISO » dans Aurora : sous chaque jeu, il indique s'il se joue depuis la console ou le PC, ou que le PC est éteint.

Si le PC s'arrête brutalement (coupure de courant, plantage), les jeux du PC restent visibles jusqu'au prochain démarrage de NetISO Manager. La console affiche alors « PC not reachable » si vous en lancez un.

Jouer sur le PC avec Xenia

Vos jeux peuvent aussi tourner sur le PC dans l'émulateur Xenia, que vous installez vous-même. Sélectionnez un jeu dans la zone 2 et cliquez sur « Jouer sur ce PC (Xenia) ». La première fois, indiquez au logiciel où se trouve xenia_canary.exe. Tous les jeux ne fonctionnent pas dans Xenia, et il demande un PC assez puissant : un jeu qui échoue dans Xenia peut très bien marcher sur la console.

Chargements rapides

La case « Chargements rapides » est cochée par défaut : les jeux se chargent environ deux fois plus vite. Si un jeu se comporte de façon anormale, décochez-la, cliquez sur « Synchroniser avec Aurora », puis redémarrez la console.

Pour ne plus y penser

Cochez « Démarrer le serveur à l'ouverture » et « Démarrer avec Windows ». Le logiciel se lance alors tout seul avec votre PC, fenêtre réduite.

Pendant que la console lit un jeu, le PC ne se met pas en veille : un PC qui s'endort en pleine partie fait planter le jeu. Dix minutes après la dernière lecture, Windows peut de nouveau se mettre en veille comme d'habitude.

Si votre box donne une nouvelle adresse au PC (souvent après son redémarrage), NetISO Manager s'en aperçoit en quelques minutes et écrit la nouvelle sur la console. Il vous demande alors de redémarrer la console.

Jeux sur plusieurs disques

Un jeu qui tient sur plusieurs disques n'occupe qu'une seule place dans Aurora. Vous choisissez le disque avec la manette, au moment de lancer le jeu :

GesteRésultat
A seulLance le dernier disque utilisé
A, puis maintenir la gâchette droitePasse au disque suivant
A, puis maintenir la gâchette gaucheRevient au disque précédent

Vous avez environ deux secondes après l'appui sur A pour presser la gâchette. Le plus simple est de la garder enfoncée dès que l'écran devient noir.

Quand un jeu vous demande le disque 2 : revenez à Aurora, puis relancez le même jeu en maintenant la gâchette droite. Votre sauvegarde reprend sur le nouveau disque.

Vous pouvez aussi choisir le disque sur le PC : sélectionnez le jeu dans la zone 2 et cliquez sur « Changer de disque ».

Une tuile démarre sur le disque de jeu, pas sur un disque d'installation ou de voix : pour Watch_Dogs, le disque 2 (le jeu) plutôt que le disque 1 (l'installation). La liste indique le rôle de chaque disque, par exemple « 1 sur 2 (installation) ». Pour installer depuis ce disque, lancez la tuile en maintenant la gâchette gauche.

Vous préférez voir tous les disques dans Aurora ?

Décochez « Une seule tuile par jeu multi-disques » sous la liste des jeux, puis cliquez sur « Synchroniser avec Aurora » et relancez un scan. Chaque disque a alors sa propre place dans Aurora et se lance directement, sans passer par les gâchettes.

En cas de problème

Commencez par « Tester ma configuration » dans la zone 3. Il vérifie le serveur, le réseau Windows, la console, le plugin et l'adresse utilisée par le plugin, et dit quoi faire pour chaque problème. Si vous demandez de l'aide sur un forum, cliquez dans cette fenêtre sur « Copier un rapport de diagnostic » et collez le texte dans votre message : il ne contient ni mot de passe, ni adresse complète, ni nom d'utilisateur.

Ce que vous voyezCe qu'il faut faire
La console affiche « PC not reachable »Lancez « Tester ma configuration ». Causes habituelles : le serveur est arrêté, Windows classe votre réseau comme Public (Paramètres Windows > Réseau et Internet > Ethernet ou Wi-Fi > Type de profil réseau > Privé), ou l'adresse du PC a changé et la console n'a pas encore été redémarrée.
Le jeu ne démarre pas et vous revenez à AuroraVérifiez que le PC est allumé, que NetISO Manager est ouvert et que la zone 4 indique « En marche ». Le journal doit afficher « Console connectée ».
Le journal n'affiche jamais « Console connectée »Refaites l'étape 3 puis redémarrez la console. Vérifiez aussi le pare-feu de Windows (étape 1). Si l'adresse IP du PC a changé, refaites l'étape 3.
« Le port 4323 est déjà utilisé »Un autre programme occupe ce port : un autre serveur NetISO resté ouvert, ou parfois un antivirus. Fermez l'autre serveur. Si rien n'y fait, redémarrez le PC.
« Échec de la synchronisation »Aurora doit être ouvert sur la console pendant la synchronisation. Vérifiez l'adresse IP de la console. L'utilisateur et le mot de passe FTP sont ceux d'Aurora (xboxftp / xboxftp par défaut).
Les jeux n'apparaissent pas dans AuroraRefaites l'étape 5 et relancez un scan.
Un jeu apparaît sans pochetteAurora télécharge les pochettes lui-même quand la console a accès à Internet. Certains disques d'installation ou de contenu additionnel n'ont pas de pochette.
Un ISO est marqué « Ignoré » dans le journalLe fichier n'est pas un ISO Xbox 360 valide, ou sa copie n'est pas terminée. « ISO incomplet » veut dire que le fichier est plus court que le disque : le téléchargement ou la copie a été interrompu. Récupérez le fichier à nouveau.
Un jeu installé sur la console reste sur son écran de chargement (Battlefield 4...)Certains jeux ont besoin de données installées depuis leur disque. Dans un dossier de jeu, ces données sont un fichier sous Content\0000000000000000\<Title ID>\ : copiez ce dossier Content à la racine du disque dur de la console, pour que le fichier se retrouve dans Hdd1:\Content\0000000000000000\<Title ID>\. Battlefield 4 lance en plus sa campagne depuis le disque 2 : lancée depuis le disque 1, la campagne reste sur un écran noir.
Chargements lents ou saccadesReliez la console par câble Ethernet plutôt qu'en Wi-Fi, et gardez « Chargements rapides » coché.
La fenêtre « Écran de la console » reste videAurora doit être ouvert, avec son serveur HTTP activé dans ses réglages. Vérifiez aussi l'utilisateur et le mot de passe web dans la zone 3.
Antivirus. NetISO Manager communique avec votre console, sur votre réseau. Son seul accès à Internet consiste, au démarrage, à demander à GitHub si une version plus récente existe ; il n'envoie rien sur vous. Si votre antivirus l'interroge, autorisez-le sur le réseau privé.

Soutenir le projet

NetISO Manager est gratuit et le restera. S'il vous est utile, vous pouvez soutenir son développement : ko-fi.com/x360remap

Utilisez ce logiciel avec des copies de jeux que vous possédez.

Remerciements

NetISO Manager ne fait que rendre plus simple un travail que d'autres ont accompli :

  • cOz, auteur du plugin NetISO et de DashLaunch, sur lesquels tout repose ;
  • ConfusionRS, pour la distribution de NetISO adaptée à Aurora 0.7b ;
  • tuxuser, pour le serveur libre netiso-srv ;
  • muradbu, pour l'idée d'un lanceur par jeu reconnu par Aurora ;
  • Team Phoenix, pour Aurora ;
  • la communauté ConsoleMods, pour sa documentation.

NetISO Manager n'est affilié à aucun d'entre eux. Le plugin NetISO.xex reste l'œuvre de cOz : il est joint tel quel, sans modification, avec son fichier d'origine, uniquement pour simplifier l'installation.

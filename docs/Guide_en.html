NetISO Manager

Play the Xbox 360 ISOs stored on your PC straight from the Aurora game list.

What you need Setup in 5 steps Playing Multi-disc games Troubleshooting

How it works

Your ISO files stay on the PC. NetISO Manager creates a small "tile" for each game and sends it to the console. Aurora shows that tile like any other game, with its cover. When you launch the game, the console reads it from the PC over the network.

So the PC must stay on, with NetISO Manager open, while you play these games. Games already installed on the console keep working whether the PC is on or not.

What you need

  • An RGH or JTAG Xbox 360 with Aurora and DashLaunch installed.
  • The NetISO.xex file (NetISO 1.0 plugin by cOz). It is not included with this software.
  • A 64-bit Windows PC.
  • The console and the PC on the same network, preferably with an Ethernet cable.
  • Your games as .iso files, or as game folders (a folder that holds default.xex).

Setup in 5 steps

Step 1. Open NetISO Manager on the PC.

The first time the server starts, Windows may show a firewall alert. Tick "Private networks" and click "Allow access". Without it the console cannot reach the PC.

Step 2. Point it at your game folders.

In area 1, click "Add folder..." and choose the folder that holds your games, whether they are ISOs or game folders. Repeat for every folder, even on different drives. Your games appear in area 2.

Step 3. Link the console.
  1. Turn the console on and leave it in Aurora.
  2. Find its IP address in the network settings of the console or of Aurora (example: 192.168.1.50).
  3. In area 3 of NetISO Manager, type that address in "Console IP address".
  4. Click "Install the plugin on the console". If asked, show where your NetISO.xex file is.
  5. Restart the console.

You only do this once.

Step 4. Send your games.

Check that area 4 says "Running". If not, click "Start server". Then click "Sync with Aurora" and wait for "Done" in the log.

Step 5. Show the folder to Aurora.
  1. In Aurora, open the settings, Content section, then the scan path manager.
  2. Add the path Hdd1:\NetISO with a scan depth of 2.
  3. Run a scan.

You only do this once. Your games appear in the list with their covers.

Playing

  1. On the PC, NetISO Manager is open and its server is "Running".
  2. On the console, pick a game in Aurora and press A.
  3. The screen stays black for a second or two, then the game starts.

To quit: Guide button, then back to Aurora, like any other game.

Adding a game later

Copy the new ISO or game folder into one of your folders. NetISO Manager notices it and offers to transfer it. Answer "Yes", then run a scan in Aurora.

Games already installed on the console

When a game is both on the console and as an ISO on the PC, only the console copy shows up: no duplicate. If you delete the game from the console to free space, click "Sync with Aurora": it comes back, played from the PC this time.

Set and forget

Tick "Start the server when the app opens" and "Start with Windows". The software then starts with your PC, minimized.

Multi-disc games

A game that spans several discs takes a single slot in Aurora. You pick the disc with the controller as you launch the game:

ActionResult
A aloneLaunches the disc used last time
A, then hold the right triggerMoves to the next disc
A, then hold the left triggerGoes back to the previous disc

You have about two seconds after pressing A to pull the trigger. The easiest way is to hold it as soon as the screen goes black.

When a game asks for disc 2: go back to Aurora, then launch the same game again while holding the right trigger. Your save continues on the new disc.

You can also pick the disc on the PC: select the game in area 2 and click "Switch disc".

Prefer to see every disc in Aurora?

Untick "One tile per multi-disc game" under the game list, then click "Sync with Aurora" and run a scan. Each disc then has its own slot in Aurora and launches directly, without the triggers.

Troubleshooting

What you seeWhat to do
The game does not start and you are back in AuroraCheck that the PC is on, NetISO Manager is open and area 4 says "Running". The log should show "Console connected".
The log never shows "Console connected"Redo step 3 and restart the console. Also check the Windows firewall (step 1). If the PC's IP address has changed, redo step 3.
"Port 4323 is already used"Another program holds that port: another NetISO server left open, or sometimes an antivirus. Close the other server. If nothing helps, restart the PC.
"Sync failed"Aurora must be open on the console during the sync. Check the console's IP address. The FTP user and password are Aurora's (xboxftp / xboxftp by default).
The games do not show up in AuroraRedo step 5 and run a scan again.
A game shows up without a coverAurora downloads covers itself when the console has Internet access. Some install or add-on discs have no cover.
An ISO is marked "Skipped" in the logThe file is not a valid Xbox 360 ISO, or it is still being copied.
Slow loading or stutterUse an Ethernet cable instead of Wi-Fi. The console tops out at about 11 MB per second.
Antivirus. NetISO Manager sends nothing to the Internet: it only talks to your console, on your own network. If your antivirus asks, allow it on the private network.

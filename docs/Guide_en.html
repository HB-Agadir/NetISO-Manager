NetISO Manager

Play the Xbox 360 ISOs stored on your PC straight from the Aurora game list.

What you need Setup in 5 steps Playing Multi-disc games Troubleshooting

How it works

Your ISO files stay on the PC. NetISO Manager creates a small "tile" for each game and sends it to the console. Aurora shows that tile like any other game, with its cover. When you launch the game, the console reads it from the PC over the network.

So the PC must stay on, with NetISO Manager open, while you play these games. Games already installed on the console keep working whether the PC is on or not.

What you need

  • An RGH or JTAG Xbox 360 with Aurora and DashLaunch installed.
  • The NetISO.xex plugin by cOz. It ships with this software and installs in one click at step 3: there is nothing to download.
  • A 64-bit Windows PC.
  • The console and the PC on the same network, preferably with an Ethernet cable.
  • Your games as .iso files, or as game folders (a folder that holds default.xex).

Setup in 5 steps

Step 1. Open NetISO Manager on the PC.

The first time the server starts, Windows may show a firewall alert. Tick "Private networks" and click "Allow access". Without it the console cannot reach the PC.

Step 2. Point it at your game folders.

In area 1, click "Add folder..." and choose the folder that holds your games, whether they are ISOs or game folders. Repeat for every folder, even on different drives. Your games appear in area 2.

Step 3. Link the console.
  1. Turn the console on and leave it in Aurora.
  2. In area 3 of NetISO Manager, click "Find" next to "Console IP address": the software looks for the console on your network and fills in its address. If it finds nothing, read the address in the network settings of the console or of Aurora (example: 192.168.1.50) and type it.
  3. Click "Install the plugin on the console" and confirm. The software sends the plugin, gives it your PC's address and adds it to the console's startup.
  4. Restart the console.

You only do this once.

Step 4. Send your games.

Check that area 4 says "Running". If not, click "Start server". Then click "Sync with Aurora" and wait for "Done" in the log.

Step 5. Show the folder to Aurora.
  1. In Aurora, open the settings, Content section, then the scan path manager.
  2. Add the path Hdd1:\NetISO with a scan depth of 2.
  3. Run a scan.

You only do this once. Your games appear in the list with their covers.

Playing

  1. On the PC, NetISO Manager is open and its server is "Running".
  2. On the console, pick a game in Aurora and press A.
  3. The screen stays black for a second or two, then the game starts.

To quit: Guide button, then back to Aurora, like any other game.

Adding a game later

Copy the new ISO or game folder into one of your folders. NetISO Manager notices it and offers to transfer it. Answer "Yes", then run a scan in Aurora.

Games already installed on the console

When a game is both on the console and as an ISO on the PC, only the console copy shows up: no duplicate. If you delete the game from the console to free space, click "Sync with Aurora": it comes back, played from the PC this time.

Seeing the console's screen from the PC

During setup you do not need to switch HDMI inputs or look at the TV. Click "Show the console's screen" in area 3: a window shows what the console displays, with a new image about every three seconds. It is a help to follow the steps, not a video: you still need the controller to move around Aurora.

This uses Aurora's web server. If it asks for a user and password, they are the ones in Aurora's settings, under HTTP server (xboxhttp / xboxhttp by default).

Only the games you can play: the "Available games" view

Each "Sync with Aurora" also puts three small scripts in Aurora. Run one of them once, and Aurora opens on a view of the games you can actually play:

  1. In Aurora, open the utility scripts and run "NetISO Setup".
  2. Answer "Yes": Aurora restarts.

From then on, Aurora opens on the "Available games" view:

  • the games played from the PC are hidden while NetISO Manager's server is not running, and come back when it runs;
  • installation discs and voice packs, which are not games, are hidden. Every game disc stays visible: some games, such as Battlefield 4, start their campaign from disc 2.

Aurora only applies its filters when it builds its list. So when the server starts or stops, NetISO Manager restarts Aurora for you, but only if Aurora is on screen: never during a game.

To see everything again, pick the "Show All" view in Aurora's Quick View menu. You can also choose the "NetISO" subtitle in Aurora: under each game it says whether it plays from the console or the PC, or that the PC is off.

If the PC shuts down suddenly (power cut, crash), the PC games stay visible until NetISO Manager starts again. The console then shows "PC not reachable" when you launch one.

Playing on the PC with Xenia

Your games can also run on the PC in the Xenia emulator, which you install yourself. Select a game in area 2 and click "Play on this PC (Xenia)". The first time, show the software where xenia_canary.exe is. Not every game runs in Xenia, and it needs a capable PC: a game that fails there may still work fine on the console.

Fast loading

"Fast loading" is ticked by default: games load about twice as fast. If a game misbehaves, untick it, click "Sync with Aurora", then restart the console.

Set and forget

Tick "Start the server when the app opens" and "Start with Windows". The software then starts with your PC, minimized.

While the console is reading a game, the PC does not go to sleep: a PC that sleeps in the middle of a game makes the game crash. Ten minutes after the last read, Windows may sleep again as usual.

If your router gives the PC a new address (often after it restarts), NetISO Manager notices it within a few minutes and writes the new one on the console. It then asks you to restart the console.

Multi-disc games

A game that spans several discs takes a single slot in Aurora. You pick the disc with the controller as you launch the game:

ActionResult
A aloneLaunches the disc used last time
A, then hold the right triggerMoves to the next disc
A, then hold the left triggerGoes back to the previous disc

You have about two seconds after pressing A to pull the trigger. The easiest way is to hold it as soon as the screen goes black.

When a game asks for disc 2: go back to Aurora, then launch the same game again while holding the right trigger. Your save continues on the new disc.

You can also pick the disc on the PC: select the game in area 2 and click "Switch disc".

A tile starts on the game disc, not on an installation or voice disc: for Watch_Dogs, disc 2 (the game) rather than disc 1 (the installation). The list shows each disc's role, for example "1 of 2 (install)". To install from that disc, launch the tile holding the left trigger.

Prefer to see every disc in Aurora?

Untick "One tile per multi-disc game" under the game list, then click "Sync with Aurora" and run a scan. Each disc then has its own slot in Aurora and launches directly, without the triggers.

Troubleshooting

Start with "Test my setup" in area 3. It checks the server, the Windows network, the console, the plugin and the address the plugin uses, and says what to do for each problem. If you ask for help on a forum, click "Copy a diagnostic report" in that window and paste the text in your message: it holds no password, no full address and no user name.

What you seeWhat to do
The console shows "PC not reachable"Run "Test my setup". The usual causes: the server is stopped, Windows treats your network as Public (Windows Settings > Network & internet > Ethernet or Wi-Fi > Network profile type > Private), or the PC's address changed and the console has not been restarted yet.
The game does not start and you are back in AuroraCheck that the PC is on, NetISO Manager is open and area 4 says "Running". The log should show "Console connected".
The log never shows "Console connected"Redo step 3 and restart the console. Also check the Windows firewall (step 1). If the PC's IP address has changed, redo step 3.
"Port 4323 is already used"Another program holds that port: another NetISO server left open, or sometimes an antivirus. Close the other server. If nothing helps, restart the PC.
"Sync failed"Aurora must be open on the console during the sync. Check the console's IP address. The FTP user and password are Aurora's (xboxftp / xboxftp by default).
The games do not show up in AuroraRedo step 5 and run a scan again.
A game shows up without a coverAurora downloads covers itself when the console has Internet access. Some install or add-on discs have no cover.
An ISO is marked "Skipped" in the logThe file is not a valid Xbox 360 ISO, or it is still being copied. "Incomplete ISO" means the file is shorter than the disc: the download or the copy was interrupted. Get the file again.
A game installed on the console stays on its loading screen (Battlefield 4...)Some games need data installed from their disc first. In a game folder, that data is a file under Content\0000000000000000\<Title ID>\: copy that Content folder to the root of the console's hard disk, so the file ends up in Hdd1:\Content\0000000000000000\<Title ID>\. Battlefield 4 also starts its campaign from disc 2: launched from disc 1, the campaign stays on a black screen.
Slow loading or stutterUse an Ethernet cable instead of Wi-Fi, and keep "Fast loading" ticked.
The "Console screen" window stays emptyAurora must be open, with its HTTP server enabled in its settings. Also check the web user and password in area 3.
Antivirus. NetISO Manager talks to your console, on your own network. Its only Internet access is, at start-up, asking GitHub whether a newer version exists; it sends nothing about you. If your antivirus asks, allow it on the private network.
